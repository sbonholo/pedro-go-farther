# Go Farther

Space rocket game — the farther you fly, the more you collect.

Made by **Pedro** with Claude.

- Play (Claude Artifact): https://claude.ai/artifact/UAcizsMbAgcGv3y3LFFEvH

- Fonts: self-hosted woff2 in `fonts/` (from @fontsource, SIL OFL). No third-party CDNs at runtime.
